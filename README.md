# Project Kariawan

## Deskripsi
Project Kariawan adalah program Java sederhana yang dibuat untuk mempelajari konsep Object-Oriented Programming (OOP), khususnya class, object, atribut, dan method.

## Atribut
Class `Kariawan` memiliki empat atribut:
- `nik` — nomor identitas karyawan.
- `nama` — nama karyawan.
- `jabatan` — jabatan karyawan.
- `gaji` — gaji karyawan.

## Method
- `tampilkanData()` — menampilkan data karyawan.
- `bekerja()` — menampilkan informasi aktivitas karyawan.

## Object
Program menggunakan tiga object karyawan untuk menunjukkan bahwa satu class dapat digunakan untuk membuat beberapa object.

## Teknologi
- Bahasa pemrograman: Java
- IDE: NetBeans 8.2

## Cara Menjalankan
1. Buka NetBeans 8.2.
2. Pilih **File → Open Project**.
3. Pilih folder project `kariawan`.
4. Jalankan class utama `main`.

## Tujuan
Memahami penerapan class, object, atribut, method, dan pembuatan object dalam pemrograman Java.
